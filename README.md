# Lifelong Learning Townsville
A Docker-based WordPress website developed for the CP3402 Supplementary Assignment. 
The project demonstrates local development, version control, cloud deployment, 
and automated theme deployment using GitHub Actions.
## Technologies Used

- WordPress
- Docker
- Docker Compose
- GitHub
- GitHub Actions
- AWS Lightsail
- Astra Parent Theme
- Astra Child Theme
## Features

- Responsive WordPress website
- Custom child theme
- Docker local development environment
- Automated deployment pipeline
- Cloud-hosted production environment
- Community-focused design
